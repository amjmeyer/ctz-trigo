III. Le repère

Ces réglages de #trig-circle(…) concernent le repère orthonormé dans lequel le cercle est tracé. À part les axes, rien n’est affiché par défaut. Pour bien les voir, les exemples partent d’un cercle nu (remarkable: false, voir la partie II).

show-axesbool
Affiche les deux axes, terminés par une flèche.
Défaut : true
#trig-circle(radius: 1.5, remarkable: false, show-axes: false)

show-originbool
Écrit le nom 𝑂 de l’origine du repère, en bas à gauche du centre.
Défaut : false
Avec les valeurs remarquables
Quand les valeurs remarquables sont affichées (show-values: true, le réglage par défaut), le centre porte déjà la valeur 0 : le nom 𝑂 n’est alors pas écrit, même avec show-origin: true.
show-ticksbool
Ajoute une graduation aux points d’abscisse ±1 et d’ordonnée ±1, avec leur valeur : sous l’axe des abscisses, à gauche de l’axe des ordonnées.
Défaut : false
#trig-circle(
  radius: 1.5,
  remarkable: false,
  show-origin: true,
  show-ticks: true,
)

show-vectorsbool
Dessine les vecteurs 𝑖⃗ et 𝑗⃗ du repère.
Les axes perdent alors leur flèche, pour que le sens de chaque axe ne soit indiqué qu’une seule fois.
Défaut : false
show-directionbool
Ajoute une flèche rouge, marquée +, qui indique le sens direct (le sens inverse des aiguilles d’une montre).
Défaut : false
#trig-circle(
  radius: 1.5,
  remarkable: false,
  show-origin: true,
  show-vectors: true,
  show-direction: true,
)

show-real-lineautobool
Affiche la droite réelle : la tangente au cercle au point 𝐼(1;0), orientée vers le haut, sur laquelle on lit les réels qu’on enroule sur le cercle.
Avec auto, elle n’apparaît que si la figure contient un tc-wind ou un tc-interval (voir la partie VII).
Défaut : auto
real-line-labelcontent
Le nom écrit en haut de la droite réelle. Par défaut, il est en anglais, comme le reste du paquet : on le remplace en général par [axe réel] ou [droite des réels].
Défaut : [real line]
#trig-circle(
  radius: 1.5,
  remarkable: false,
  show-real-line: true,
  real-line-label: [axe réel],
)
