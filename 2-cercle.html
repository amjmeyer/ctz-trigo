II. Le cercle

Le cercle s’écrit #trig-circle(…). Entre les parenthèses, on met les réglages du cercle, et les éléments à ajouter dessus (voir la partie I). Cette partie détaille les réglages de ce qui est affiché et de l’allure du cercle ; ceux du repère sont dans la partie III.

trig-circle(
  ..éléments,
  // ce qui est affiché (cette partie)
  remarkable: bool,
  show-values: bool,
  show-angles: bool,
  show-lines: bool,
  show-points: auto | bool,
  minus-pi: bool,
  show-tan: bool,
  // l'allure (cette partie)
  radius: int | float,
  thickness: length,
  margin: int | float,
  circle-color: color,
  background: color,
  values-size: length,
  angles-size: length,
  names-size: length,
  angles-offset: length,
  // le repère (partie III)
  show-axes: bool,
  show-origin: bool,
  show-ticks: bool,
  show-vectors: bool,
  show-direction: bool,
  show-real-line: auto | bool,
  real-line-label: content,
) -> content

Ce qui est affiché

Par défaut, trig-circle() dessine le cercle de ProfLycee : les valeurs remarquables du cosinus et du sinus sur les axes, les angles remarquables autour du cercle, et les traits de construction en pointillés qui les relient.

remarkablebool
Ce paramètre est un interrupteur général. Réglé sur false, il retire d’un coup les valeurs, les angles et les traits de construction : il reste un cercle nu, avec ses axes, sur lequel on ajoute ce qu’on veut.
C’est le point de départ de la plupart des exemples de cette documentation.
Défaut : true
#trig-circle(radius: 1.5, remarkable: false)

Comment fonctionne cet interrupteur ?
Avec remarkable: false, les trois paramètres show-values, show-angles et show-lines ci-dessous sont ignorés. Pour n’en afficher que certains, on laisse remarkable sur true et on désactive les autres un par un.
show-valuesbool
Affiche les valeurs remarquables du cosinus (sur l’axe des abscisses) et du sinus (sur l’axe des ordonnées) : 12, 22, 32 et leurs opposés.
Défaut : true
show-anglesbool
Affiche les angles remarquables autour du cercle : 𝜋6, 𝜋4, 𝜋3, 𝜋2, etc.
Défaut : true
show-linesbool
Affiche les traits de construction en pointillés : les rayons vers les points remarquables et les rectangles qui relient ces points aux valeurs sur les axes.
Défaut : true

Ci-dessous, on a gardé les valeurs et les angles, mais retiré les traits :

#trig-circle(radius: 2.5, show-lines: false)

show-pointsautobool
Marque d’un très petit point noir les points du cercle associés aux angles remarquables.
Avec auto, ces points sont affichés seulement quand les angles et les traits le sont. On peut forcer leur affichage avec true, même sur un cercle nu.
Défaut : auto
#trig-circle(
  radius: 2,
  remarkable: false,
  show-points: true,
)

Un gabarit pour les élèves
Un cercle nu avec ses seuls points remarquables fait un bon support d’exercice : les élèves y placent eux-mêmes les angles et les valeurs.
minus-pibool
Choisit l’intervalle dans lequel sont écrits les angles remarquables.
Par défaut (true), ils sont donnés dans ]−𝜋;𝜋], c’est-à-dire par leur mesure principale. Avec false, ils sont donnés dans [0;2𝜋[.
Défaut : true
#trig-circle(radius: 2.5, minus-pi: false, show-lines: false)

show-tanbool
Ajoute la tangente au cercle au point 𝐼(1;0), avec les valeurs remarquables de la tangente (33, 1, 3 et leurs opposés) et les traits qui les relient au centre.
Défaut : false
#trig-circle(
  radius: 2,
  show-tan: true,
  show-lines: false,
)

L’allure du cercle

radiusintfloat
Le rayon du cercle, en centimètres. Il doit être strictement positif.
Les valeurs et les angles remarquables gardent la même taille quel que soit le rayon : sur un petit cercle, ils se chevauchent vite. En dessous d’un rayon de 2, mieux vaut n’afficher qu’une partie des informations, comme le montre ce cercle de rayon 1,5.
Défaut : 3
#trig-circle(radius: 1.5)

thicknesslength
L’épaisseur du cercle et des axes. C’est aussi l’épaisseur par défaut des rayons et des vecteurs (partie V).
Défaut : 1pt
marginintfloat
La longueur, en centimètres, dont les axes dépassent du cercle.
Défaut : 0.25
circle-colorcolor
La couleur du cercle (les axes restent noirs).
Défaut : black
#trig-circle(
  radius: 1.5,
  remarkable: false,
  thickness: 2pt,
  margin: 0.6,
  circle-color: blue,
)

backgroundcolor
La couleur du fond placé derrière les valeurs et les angles remarquables (pour qu’ils restent lisibles par-dessus les traits), et à l’intérieur des marques creuses des points (partie IV).
À changer si la page n’est pas blanche, pour que ces fonds ne se voient pas.
Défaut : white
#block(fill: yellow.lighten(70%), inset: 8pt,
  trig-circle(radius: 2, background: yellow.lighten(70%)),
)

values-sizelength
La taille du texte des valeurs remarquables (cosinus, sinus, tangente).
Défaut : 7pt
angles-sizelength
La taille du texte des angles remarquables.
Défaut : 8pt
angles-offsetlength
La distance entre le cercle et les angles remarquables écrits autour.
Défaut : 10pt
names-sizelength
La taille des noms des éléments ajoutés (points, rayons, arcs…), pour un rayon jusqu’à 1 cm. Au-delà, elle grandit avec le cercle (voir la partie I).
Défaut : 9pt
#trig-circle(
  radius: 2.5,
  show-lines: false,
  values-size: 9pt,
  angles-size: 11pt,
  angles-offset: 16pt,
)
