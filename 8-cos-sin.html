VIII. Cosinus et sinus

Le cosinus et le sinus d’un angle

tc-cos-sin(θ, nom) dessine, pour un angle 𝜃 :

  • le point 𝑀(cos𝜃;sin𝜃) du cercle et le rayon [𝑂𝑀] ;
  • l’angle 𝜃, marqué autour de O ;
  • les projections de 𝑀 sur les axes, en pointillés ;
  • le cosinus (en bleu) sur l’axe des abscisses et le sinus (en rouge) sur l’axe des ordonnées, avec leur nom cos(𝜃) et sin(𝜃).
tc-cos-sin(
  angle,             // int | float | angle
  nom,               // facultatif : content | none
  angle-name: content,
)

Le nom du point est 𝑀 si on n’en donne pas.

#trig-circle(
  radius: 2,
  remarkable: false,
  tc-cos-sin(130deg),
)

angle-namecontent
Le nom de l’angle, repris dans cos(𝜃) et sin(𝜃).
Défaut : $theta$
#trig-circle(
  radius: 2,
  remarkable: false,
  tc-cos-sin(-50, $P$, angle-name: $x$),
)

Les équations cos𝑥=cos𝛼 et sin𝑥=sin𝛼

tc-cos-eq(α) dessine les deux points du cercle dont le cosinus vaut cos𝛼 (ils sont symétriques par rapport à l’axe des abscisses), reliés par un segment vertical. tc-sin-eq(α) fait de même pour le sinus (points symétriques par rapport à l’axe des ordonnées, segment horizontal). Ces deux éléments ne prennent pas de nom.

tc-cos-eq(
  angle,             // int | float | angle
  color: color,
  lines: bool,
)
colorcolor
La couleur des points, du segment et des rayons.
Défaut : blue
linesbool
Trace en tirets les rayons qui mènent aux deux solutions.
Défaut : true
#trig-circle(
  radius: 2.5,
  show-angles: false,
  show-lines: false,
  tc-cos-eq(60),
)

tc-sin-eq prend les mêmes paramètres :

#trig-circle(
  radius: 2.5,
  minus-pi: false,
  show-lines: false,
  tc-sin-eq(-30, color: red, lines: false),
)
