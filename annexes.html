Correspondance avec ProfLycee

Pour qui connaît la commande \CercleTrigo de ProfLycee, voici l’équivalent de ses clés.

\CercleTrigoctz-trigo
Rayonradius:
Epaisseurthickness:
Margemargin:
TailleValeursvalues-size:
TailleAnglesangles-size:
CouleurFondbackground:
Decalangles-offset:
MoinsPiminus-pi:
AffAnglesshow-angles:
AffTraitsshow-lines:
AffValeursshow-values:
ValeursTanshow-tan:
EquationCos, cos, CouleurSol, AffTraitsEqtc-cos-eq(angle, color: …, lines: …)
EquationSin, sintc-sin-eq(angle)
Point, NomPt, Angletc-cos-sin(angle, nom, angle-name: …)

Tout le reste (repère, droite réelle, points, rayons, vecteurs, arcs, angles, enroulement, trig-circle-draw) est un ajout de ctz-trigo.

Les messages d’erreur

Un réglage mal écrit arrête la compilation avec un message clair (en anglais), qui nomme la fonction en cause. Par exemple :

  • une clé inconnue : trig-circle: unknown key "raduis" ;
  • un angle qui n’en est pas un : tc-point: an angle must be a number of
    degrees (45) or an angle (45deg, 1rad), not "45"     ;
  • un rayon nul ou négatif, une marque inconnue, plusieurs noms pour un même élément…

Remerciements

Un grand merci à Cédric Pierquet, auteur du package LaTeX ProfLycee : ctz-trigo reprend l’allure et les réglages de sa commande \CercleTrigo. Le code, lui, est entièrement réécrit.

Dépendances
